### 注意：两个白名单易混淆
- **小程序 API IP 白名单**（`49.234.141.38`，云托管容器调微信开放接口用，生成小程序码需要）→ 已加。
- **小程序代码上传白名单**（miniprogram-ci 从本机直连上传用）→ 需加**本机出口 IP**。本机 `servicewechat.com` 解析在 IPv4/IPv6 间**随机漂移**：IPv4 走 NAT 出口 **`139.226.63.67`**（非本机 `144.24.67.252`、非 `49.234.141.38`，已加 ✅）；IPv6 走 **`2408:820c:680a:fc0:1123:a12b:d44e:7475`**（未加 ❌）。两个都加入「开发管理 → 开发设置 → 小程序代码上传白名单」可彻底消除 `invalid ip` 随机失败。上传命令加 `NODE_OPTIONS=--dns-result-order=ipv4first` 可大概率走低延迟 IPv4，但仍偶发 IPv6。

### v2.5.2 附带：注销账号
- 新增 `POST /api/auth/delete-account`（需登录）：级联删除该用户业务数据 + 登录会话 + 用户本身，释放其 openid/用户名。**用途**：清理之前微信扫码生成的「孤儿账号」，删后该微信即可绑定到注册账号（绑定冲突时先用此功能清孤儿）。
