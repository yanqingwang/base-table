# 2026-09-06 工作日志

## 小程序取消强制登录（次卡管家 / card-counter-miniapp）
- 问题：所有页面 `onLoad/onShow` 调 `ensureLogin()`，无 token 即 `wx.navigateTo` 跳登录页 → 强制登录墙；且本地页 `loadData` 里 `if(!token) await wechatLogin()` 无 token/云未就绪会抛错致整页空白。
- 改动：
  - `app.js`：`ensureLogin()` 不再跳转，直接 `return true`（可选登录）；新增 `bestEffortSync()`（try/catch 包裹登录+pull，失败仅 warn）。
  - 本地页 `loadData` 统一把「先登录再 pull」替换为 `await app.bestEffortSync()`：index/stats/checkin/checkin-history/quota-detail/profile（rating 本就 storage-first 容错）。
  - 服务端页（card/order/merchant/groupbuy）靠 `callApi` 401→静默 `wechatLogin`→重试，无墙。
- 校验：`node --check` 全部通过。
- 效果：核心次卡管理可不登录/离线使用，登录后后台静默同步；登录页保留为可选入口。
- 记忆原则已写入 `MEMORY.md`「产品/UX 原则」一节。
