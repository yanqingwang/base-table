## 1. 背景与目标

商业化 demo 的后端已积累大量能力（核销明细、储值余额、订单、RFM 客群分层、异常告警、合规状态、行业模板），但**商户网页端只暴露 6 个操作型 Tab**，这些"经营价值"数据在 UI 上不可见；平台侧也只有"租户管理"、无跨租户总览。

本次补齐商业化产品中"**让商户一眼看到生意**"的能力（对应 v3 方案 M3 增强里的"报表"）：

- **商户经营看板**：把会员/卡/核销/收入/风险/客群/合规串成一张"经营体检表"。
- **平台总览**：跨租户（企业）汇总 KPI，供平台超管 Web 后台。

两者均为**纯读取聚合**，不改任何资金链路、不新增写路径。

## 2. 交付内容

### 2.1 后端

| 项 | 文件 | 说明 |
|---|---|---|
| 服务 | `src/backend/services/dashboard.py`（新增） | `merchant_dashboard()` / `platform_overview()` / `compliance_summary()`；纯读取 |
| 路由 | `src/backend/routes/__init__.py` | `GET /api/merchant/dashboard`（`view_report` 权限）；`GET /api/platform/overview`（平台超管） |

#### `GET /api/merchant/dashboard?days=14`（商户，`view_report`）
返回字段：
- `org`：门店数 / 员工数
- `cards`：总数 / 活跃 / 待领取 / `byStatus` 明细
- `remaining`：`totalRemainingTimes`（次数卡可用余量，排除不限次月卡）/ `totalBalanceCents`（储值余额）
- `customers`：会员总数 / `new7d` / `new30d`（按"该顾客在本商户首张卡时间"计新客）
- `redemptions`：`total/today/last7d/last30d/revoked` + `trend`（近 N 日逐日核销数，默认 14 天）
- `revenue`：已支付订单数 / 累计收款 / 近30日收款（来自 `Order.paidAmount`）
- `alerts`：未处理告警数 / 其中 `critical`
- `expiring`：`within7d` / `within30d` 到期活跃卡
- `segments`：复用 RFM 客群分层汇总（标签占比）
- `compliance`：合规包开关 + 对客徽标（`none/partial/verified`，与卡详情徽标同口径）
- `topTemplates`：按发卡量排序的热销卡模板 Top N

#### `GET /api/platform/overview`（平台超管）
- `tenants`：企业总数 / 正常 / 停用
- `totals`：门店 / 员工 / 发卡 / 会员 / 储值余额 / 累计收款 / 近30日核销 / 未处理告警
- `byMerchant`：各企业明细（发卡、近30日核销、累计收款、合规徽标），按累计收款降序

## 4. 数据口径与设计约束

1. **纯读取**：看板不写任何表；RFM 复用纯计算 `segment_summary`，异常时降级为空不阻断看板。
2. **方言无关**：核销趋势在 Python 侧按日分桶，避免依赖 SQLite/MySQL 日期函数差异；聚合用 SQL `COUNT/SUM`。
3. **时间口径**：统一 UTC（与模型 `createdAt=server_default=now()` 一致）。
4. **不变量保持**：`usedTimes/balanceCents/...` 仍由服务端派生，看板只读不覆盖。
5. **合规口径一致**：徽标逻辑与 `card_customer_detail` 完全一致（`approved + connected → verified`）。

## 5. 环境注意（本次踩坑）

- 本机 `/tmp` 是 **仅 10MB 的 tmpfs**，而 `make_app()` 用 `tempfile.mkstemp()` 建临时 SQLite 库 → 跑测试会 **"database or disk is full"** 假性失败。
  **解决：跑测试前设 `TMPDIR=/home/wang/wk/tmp`（大盘目录）。**
- 系统 Python 受 PEP 668 保护，依赖需装进仓内 venv：`python3 -m venv .venv && .venv/bin/pip install Flask==3.1.3 SQLAlchemy==2.0.51`。
