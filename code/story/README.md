# 小豹子的成长之旅 — 项目记忆

## 项目概况

儿童教育系列童话，适合7-8岁女孩子，培养勇敢、坚强、果断、坚持等品格。

| 项目 | 内容 |
|------|------|
| **主角** | 小豹子（8岁江南女孩） |
| **伙伴** | 咪咪（橘色猫咪） |
| **故事数** | 10个系列故事，同一个主角的成长 |
| **语言** | 中文，全文拼音标注（HTML ruby） |
| **排版** | A4双栏打印布局，每页2个故事 |
| **插图** | SVG简笔水墨风，每页嵌入 |

## 目录结构

```
story/
├── README.md           ← 本文件（项目记忆）
├── gen_stories.py      ← 生成脚本（Python）
├── index.html          ← 输出文件（可直接打开）
└── audio/              ← AI 语音文件
    ├── 01-courage.mp3
    ├── 02-resilience.mp3
    └── ...
```

## 技术栈

- **文本生成**: Python + pypinyin（拼音标注）
- **插图**: SVG 手绘（Python 直接输出）
- **排版**: HTML/CSS A4双栏 grid 布局
- **语音**: edge-tts（微软 Xiaoxiao 中文神经语音）→ 16kbps MP3
- **播放**: HTML5 Audio API

## 生成命令

```bash
cd /home/wang/wk/code/story
python3 gen_stories.py
```

## 注意事项

- 如需重新生成语音，删除 `audio/*.mp3` 再运行脚本
- 语音直接访问微软 Edge TTS 服务，需联网
- 打印用浏览器打开 index.html → Ctrl+P → A4
