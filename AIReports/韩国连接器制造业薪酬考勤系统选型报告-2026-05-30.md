# 韩国连接器制造业薪酬考勤系统选型报告

**目标企业**：美国母公司旗下韩国连接器制造工厂
**规模**：韩国约 1,000 人，24 小时轮班制
**HRSSC**：中国苏州（覆盖亚太，需远程管理韩国薪酬数据）
**现有系统**：Douzon ERP 薪酬模块（可续约，供应商停止主动更新）
**总部标准**：美国总部使用 ADP
**约束**：无强制系统要求，成本敏感
**报告日期**：2026 年 5 月 30 日

---

## 第一部分：需求澄清与关键约束

### 理解偏差修正

| 偏差项 | 之前理解 | 修正后理解 |
|--------|---------|-----------|
| 覆盖范围 | 中韩双轨 + 亚太扩展 | **仅韩国 1,000 人**；中国、日本暂不需纳入本次选型 |
| 替换紧迫度 | Douzon 已停止维护，6-9 个月紧急切换 | **可续约，有缓冲期**；可从容完成 POC、谈判和并行测试 |
| 行业特征 | 一般制造业 | **汽车连接器制造**，24 小时轮班；客户为汽车行业，可能存在供应链追溯要求 |
| 总部约束 | 已有 SuccessFactors + SAP S/4 | **美国总部使用 ADP**，无强制 SAP 要求 |
| 成本态度 | 预算可接受 550-780 万 | **成本敏感**，若性价比不突出则默认选 ADP |

### 核心需求提炼

1. **韩国薪酬 100% 合规**：四大保险（国民年金、健康保险、雇佣保险、产灾保险）、退职金、所得税、52 小时周工时上限
2. **24 小时轮班考勤**：连接器制造业典型为 3 班倒（早/中/夜），需支持复杂排班、加班计算、换班调休
3. **苏州 SSC 远程可视**：亚太 HRSSC 需能查看韩国薪酬数据、生成区域汇总报表，但不需要直接操作系统
4. **与美国 ADP 总部对接**：韩国薪酬数据需能上报美国总部，支持全球人力成本汇总
5. **服务可持续性**：替换 Douzon 的核心原因是供应商停止更新，新方案必须有长期服务保障

### 二、方案 A：ADP Streamline / GlobalView ★ 基准方案

#### 方案描述
接入美国总部已有的 ADP 全球薪酬网络，韩国工厂使用 ADP Streamline（跨国企业标准化薪酬）或 ADP GlobalView（集中式全球 HCM）。苏州 SSC 通过 ADP 全球门户查看韩国数据。

#### 优势

| 维度 | 说明 |
|------|------|
| **与美国总部一致性** | 数据模型、报表格式、接口标准与美国总部完全一致；全球人力成本汇总无需转换 |
| **韩国合规** | ADP Korea 有四大保险、退职金、所得税的预配置规则；法规更新由 ADP 韩国团队负责 |
| **服务可持续性** | ADP 全球 Top 3 薪酬服务商，不存在供应商终止风险 |
| **苏州 SSC 可视** | ADP GlobalView 提供区域管理层视图，苏州 SSC 可直接登录查看韩国薪酬报表 |
| **实施风险低** | 总部已有 ADP，韩国接入属于"扩展站点"，方法论成熟 |

#### 劣势与成本顾虑

| 维度 | 说明 |
|------|------|
| **价格高昂** | ADP Streamline 人均年费通常为 $150-250/人（韩国地区），1,000 人规模年订阅约 **$15-25 万（约 ¥108-180 万）**；加上实施费，3 年 TCO 通常在 **¥400-600 万** |
| **定制化受限** | 连接器制造业的特殊排班规则、质量停线工时追溯等需求，ADP 标准化产品可能无法深度支持 |
| **24小时轮班考勤** | ADP 的考勤模块（ADP Time & Attendance）在韩国制造业的轮班支持不如本土系统灵活；可能需要第三方考勤硬件 + 定制接口 |
| **响应速度** | 韩国本地服务响应可能不如韩国本土供应商（Duzon）快速 |

#### 成本估算（1,000 人，3 年）

| 项目 | 金额（人民币） |
|------|:------------:|
| 实施费（站点扩展配置 + 韩国本地化） | 80-150 万 |
| 年订阅费（含薪酬 + 基础 HR） | 108-180 万/年 |
| 考勤硬件（如需第三方） | 20-40 万 |
| ADP → 苏州 SSC 报表配置 | 10-20 万 |
| **3 年 TCO** | **约 450-750 万** |

### 三、方案 B：SAP SuccessFactors EC Payroll (Korea)

#### 方案描述
在现有 SuccessFactors Employee Central 基础上，启用韩国本地化薪酬引擎（EC Payroll）。苏州 SSC 通过 SF 报表查看数据，与美国 ADP 对接需通过 API 或文件接口。

#### 前提条件
**必须确认：韩国工厂是否已有 SuccessFactors Employee Central？**
- 若有 → 直接叠加 EC Payroll 模块，实施周期 4-6 个月
- 若无 → 需先上 EC Core，再上 Payroll，实施周期 6-9 个月，成本大幅增加

#### 优势

| 维度 | 说明 |
|------|------|
| **韩国合规深度** | SAP 韩国官方维护四大保险、退职金规则；52 小时工时管控原生支持 |
| **制造业考勤** | SAP SuccessFactors Time Tracking 支持复杂轮班；或与 SAP Fieldglass 劳动力管理结合 |
| **苏州 SSC 体验** | 若苏州 SSC 也使用 SF，则平台统一；报表工具（Workforce Analytics）功能强大 |
| **亚太扩展** | 未来若越南/泰国设厂，可直接叠加对应国家 Payroll 引擎 |

#### 劣势

| 维度 | 说明 |
|------|------|
| **与美国 ADP 对接** | 非原生；需开发 SF → ADP 的数据接口（员工主数据、薪酬汇总），一次性开发成本 20-40 万，年维护 5-10 万 |
| **实施复杂度** | 韩国 Payroll 配置复杂（~150 个 wage types），需要 SAP 韩国认证伙伴；Douzon 数据迁移工作量大 |
| **成本不低** | 虽然低于 ADP，但 1,000 人规模的 SF EC Payroll 3 年 TCO 仍在 **¥300-500 万** |
| **服务可持续性** | SAP 长期可靠，但韩国 Payroll 的本地化支持依赖韩国实施伙伴生态 |

#### 成本估算（1,000 人，3 年，假设已有 SF EC）

| 项目 | 金额（人民币） |
|------|:------------:|
| EC Payroll Korea 许可（3 年） | 60-100 万 |
| 韩国实施服务（配置 + 迁移 + 并行测试） | 80-150 万 |
| SF → ADP 接口开发 | 20-40 万 |
| 考勤硬件（Suprema 等） | 20-35 万 |
| 年订阅/维护 | 40-70 万/年 |
| **3 年 TCO** | **约 280-500 万** |

### 四、方案 C：Duzon iCUBE Cloud（升级延续）

#### 方案描述
不替换 Douzon，而是将现有 Douzon ERP 薪酬模块升级至 iCUBE Cloud 版本。保持韩国本土供应商，最大化延续性。

#### 优势

| 维度         | 说明                                           |
| ---------- | -------------------------------------------- |
| **延续性最佳**  | 现有 Douzon 数据、流程、用户习惯完全保留；升级而非替换，学习成本最低       |
| **韩国本土合规** | Duzon 是韩国制造业市占率第一的 ERP；四大保险、退职金、52 小时工时支持最深度 |
| **24小时轮班** | Duzon 有制造业考勤模块，与薪酬原生集成；轮班、加班、换班逻辑成熟          |
| **成本最低**   | 升级费用远低于替换；年订阅也低于 ADP/SAP                     |
| **响应速度**   | 韩国本土供应商，现场支持最快                               |

#### 劣势（致命）

| 维度             | 说明                                                                   |
| -------------- | -------------------------------------------------------------------- |
| **供应商风险未消除**   | Douzon 已宣布停止维护，iCUBE Cloud 的可持续性存疑；今天升级 Cloud，3 年后可能再次面临同样问题         |
| **与美国 ADP 对接** | 需定制开发 Douzon → ADP 接口；Duzon 的 API 开放度不如 SAP/ADP                      |
| **苏州 SSC 可视**  | Douzon 无英文界面或全球门户；苏州 SSC 查看韩国数据需额外开发报表或依赖韩国 HR 手工导出                  |
| **亚太扩展**       | 无法支持越南/泰国等其他国家；每扩展一个国家需重新选型                                          |
| **服务可持续性**     | ⚠️ **这是核心风险**。用户选择替换 Douzon 的根本原因正是供应商停止更新。升级 Cloud 可能只是延迟问题，而非解决问题。 |

#### 成本估算（1,000 人，3 年）

| 项目 | 金额（人民币） |
|------|:------------:|
| iCUBE Cloud 升级费 | 30-60 万 |
| 年订阅 | 30-50 万/年 |
| Douzon → ADP 接口（如做） | 30-50 万 |
| 苏州 SSC 报表开发 | 20-40 万 |
| **3 年 TCO** | **约 180-340 万** |

**评估结论**：成本低但**服务可持续性风险未解决**，不推荐作为长期方案。仅可作**6-12 个月应急续约**期间的过渡。

### 五、方案 D：CDP WorkLife + 韩国本地 Payroll 服务

#### 方案描述
采用 CDP集团（跨国人力资源服务商）的 WorkLife 平台作为苏州 SSC 的统一视图层，韩国薪酬由 CDP 韩国团队或本地合作商（如 Saramin、Incruit HR）处理。本质上是"平台 + BPO"混合模式。

#### 优势

| 维度 | 说明 |
|------|------|
| **性价比** | 比 ADP 便宜 20-40%；比 SAP 实施周期短 |
| **苏州 SSC 统一视图** | CDP WorkLife 提供多国家薪酬 dashboard，苏州 SSC 可在一个界面查看韩国、中国、越南等数据 |
| **韩国本地服务** | CDP 在韩国有合作网络，可确保四大保险、退职金合规 |
| **与美国 ADP 对接** | CDP 有全球薪酬汇总经验，可通过标准 API 或文件向 ADP 上报数据 |

#### 劣势

| 维度 | 说明 |
|------|------|
| **品牌知名度** | CDP 在韩国制造业不如 ADP/SAP/Duzon 有口碑；客户案例需仔细验证 |

| **数据主权** | 薪酬数据经 CDP 平台处理，需确认是否符合韩国 PIPA 和美国 SOX 合规 |

| 排名 | 方案 | 加权分 | 适用场景 |

## 第四部分：决策建议

### 一、如果预算不是硬约束 → 选 ADP Streamline

**核心理由**：
1. **"否则 ADP" 的逻辑自洽**：用户自己设定了 ADP 为默认选项，而综合评分 ADP 确实最高
2. **消除苏州 SSC 的管理复杂度**：苏州团队不需要学习韩国本土系统，直接通过 ADP 全球门户查看数据
3. **彻底消除供应商风险**：ADP 不会成为下一个 Douzon
4. **汽车行业客户信任**：汽车供应链通常要求 Tier 1/2 供应商使用全球化的、可审计的 HR 系统；ADP 的合规性和审计轨迹优于韩国本土系统

**成本优化建议**：
- 与美国总部谈判**全球批量折扣**：将韩国 1,000 人纳入总部已有的 ADP 全球合同，通常可争取 15-25% 折扣
- **分阶段上线**：先上薪酬（紧急替换 Douzon），后上考勤（利用 Douzon 续约缓冲期完善轮班配置）
- **考勤模块选型灵活**：ADP 标准考勤若不支持复杂轮班，可保留第三方考勤硬件（Suprema/ZKTeco），仅将考勤结果文件导入 ADP Payroll

### 二、如果预算敏感且已有 SuccessFactors EC → 选 SAP SF EC Payroll

**前提**：确认韩国工厂已有或计划上 SuccessFactors Employee Central

**成本节省点**：
- 3 年 TCO 比 ADP 低约 **¥100-250 万**
- 利用已有 SAP 投资，避免重复建设

**额外投入**：
- SF → ADP 接口开发：一次性 20-40 万
- 苏州 SSC 可能需要额外培训 SAP 报表工具

**长期价值**：
- 若 2-3 年内计划扩展至越南/泰国，SAP 的多国家 Payroll 边际成本远低于 ADP 每个站点单独收费

### 三、如果 Douzon 续约仅 6 个月内 → 应急过渡方案

| 阶段 | 时间 | 行动 |
|------|------|------|
| 立即 | 0-1 个月 | 与 Douzon 续约 6 个月，争取数据导出支持 |
| 并行 | 1-4 个月 | 启动 ADP/SAP 选型 + POC；同时准备 Douzon 数据清洗 |
| 切换 | 4-6 个月 | 新系统并行测试；Douzon 最后 1-2 个月作为备份 |
| 终止 | 6 个月 | Douzon 正式下线 |
