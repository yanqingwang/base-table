## 3. 快速部署

### 3.1 获取代码

```bash
cd /home/wang/wk/code/easy-hire
```

### 3.2 一键启动

```bash
# 启动（自动限制 CPU + 内存不超过系统 30%）
bash start.sh
```

脚本会自动：
1. 启动后端 API 服务（端口 3201）
2. 启动前端开发服务器（端口 5174）
3. 设置 CPU 和内存限制

**停止服务**：
```bash
bash stop.sh
```

### 3.3 手动启动

**第一步：启动后端**

```bash
cd /home/wang/wk/code/easy-hire/backend

# 开发模式
cargo run

# 生产模式（编译优化）
cargo build --release
./target/release/easy-hire
```

后端监听 `http://localhost:3201`。首次运行自动创建 `easy_hire.db` 数据库文件。

**第二步：启动前端**

```bash
cd /home/wang/wk/code/easy-hire/frontend

# 安装依赖（首次）
npm install

# 开发模式
npm run dev

# 生产构建
npm run build
```

前端运行在 `http://localhost:5174`。API 请求自动代理到后端 `:3201`。

### 3.4 验证

```bash
# 后端健康检查
curl http://localhost:3201/api/v1/health
# 返回: OK

# 前端访问
# 浏览器打开 http://localhost:5174
```

### 3.5 运行测试


## 4. 配置说明

### 4.1 后端环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `EASY_HIRE_DB` | `easy_hire.db` | SQLite 数据库文件路径 |
| `EASY_HIRE_JWT_SECRET` | 内置默认值 | JWT 签名密钥（生产环境务必修改） |
| `EASY_HIRE_PORT` | `3201` | 后端监听端口 |

### 4.2 前端配置

**Vite 配置** (`vite.config.ts`)：

```typescript
export default defineConfig({
  plugins: [react()],
  server: {
    port: 5174,
    strictPort: true,
    proxy: {
      '/api': {
        target: 'http://localhost:3201',
        changeOrigin: true,
      },
    },
  },
});
```

如需修改后端地址，更新 `proxy.target`。

### 4.3 CORS 配置

后端 CORS 配置 (`backend/src/lib.rs`)：

```rust
let cors = CorsLayer::new()
    .allow_origin("http://localhost:5174".parse().unwrap())
    .allow_methods([Method::GET, Method::POST, Method::PUT, Method::DELETE, Method::OPTIONS])
    .allow_headers(Any);
```

如需添加更多允许的域名，增加 `.allow_origin()` 调用。

## 5. 数据库说明

### 5.1 数据库文件

- 文件名：`easy_hire.db`（与后端二进制同目录）
- 格式：SQLite 3
- 自动创建：首次运行 `cargo run` 时自动创建所有表结构

### 5.2 重置数据库

```bash
cd /home/wang/wk/code/easy-hire/backend
rm easy_hire.db
cargo run
```

重新启动后会自动创建新数据库。需重新注册管理员账号。

```bash
# 后端日志（systemd 方式启动）
journalctl --user -u easyhire-backend -f

# 前端日志（systemd 方式启动）

```

### 8.2 端口占用处理

```bash
# 释放 3201 端口
fuser -k 3201/tcp

# 释放 5174 端口
fuser -k 5174/tcp
```

### 8.3 资源监控

```bash
# 查看服务状态
systemctl --user status easyhire-backend
systemctl --user status easyhire-frontend

# 查看资源使用
top -p $(pgrep easy-hire)
```

### 8.4 备份数据库

```bash
cp /home/wang/wk/code/easy-hire/backend/easy_hire.db \
   /home/wang/wk/code/easy-hire/backend/easy_hire.db.$(date +%Y%m%d_%H%M%S).bak
```

### 8.5 生产部署建议

1. **数据库**：生产环境建议迁移到 PostgreSQL
   ```bash
   export EASY_HIRE_DB=postgres://user:pass@localhost/easyhire
   ```
2. **JWT 密钥**：务必修改默认 JWT 密钥
   ```bash
   export EASY_HIRE_JWT_SECRET=$(openssl rand -hex 32)
   ```
3. **HTTPS**：前端建议使用 Nginx 反向代理 + SSL
4. **进程管理**：使用 systemd 或 supervisor 管理进程

## 9. 常见问题

### Q: 启动后端提示端口被占用？
```bash
fuser -k 3201/tcp
cargo run
```

### Q: 忘记管理员密码？
```bash
rm easy_hire.db
cargo run
# 重新注册管理员账号
```

### Q: 前端页面白屏？
1. 确认后端正在运行：`curl http://localhost:3201/api/v1/health`
2. 确认前端代理配置：`vite.config.ts` 中 `proxy.target` 指向 `http://localhost:3201`
3. 检查浏览器控制台是否有错误

### Q: 如何添加种子数据？
首次启动后，系统自动插入：
- 10 个国家/地区
- 11 种币种
- 7 个默认部门

### Q: API 返回 401 Unauthorized？
1. 确认已登录：POST `/api/v1/auth/login`
2. 确认 Authorization header 格式：`Bearer <token>`
3. 确认 token 未过期

### Q: 如何查看数据库内容？
```bash
sqlite3 easy_hire.db
.tables
.schema candidates
SELECT * FROM candidates LIMIT 5;
```
