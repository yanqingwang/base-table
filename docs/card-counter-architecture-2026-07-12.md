# 次卡管家 — 架构设计文档

> 日期：2026-07-12
> 版本：v1.0

---

## 一、产品概述

次卡管家是一款基于次数记录的预充值消费管理工具，帮助用户追踪各类次卡（健身卡、课程卡等）的使用情况。

### 核心功能

1. **配额管理**：记录商家、事项、金额、总次数、到期时间、备注
2. **学习偏好**：周末/工作日/假期/寒暑假时段规划
3. **签到消费**：一键签到，支持扣减次数调整，记录商家名称
4. **商家评价**：1~5星评分，低分商家自动标记"避雷"
5. **统计分析**：剩余次数统计、过期提醒、学习建议算法
6. **数据同步**：本地存储为主，可选 CloudBase 云端同步

## 二、架构设计

### 2.1 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                        客户端层                              │
├─────────────────┬─────────────────┬─────────────────────────┤
│  V1: Web 应用   │  V2: CloudBase  │  V3: 微信小程序          │
│  (Python 服务)  │  (静态托管 SPA)  │  (web-view 壳)          │
├─────────────────┴─────────────────┴─────────────────────────┤
│                      数据层                                  │
├─────────────────┬─────────────────┬─────────────────────────┤
│  本地 JSON 文件  │  localStorage    │  CloudBase 云数据库     │
│  (data/cards)   │  (浏览器)        │  (quotas/checkins)     │
└─────────────────┴─────────────────┴─────────────────────────┘
```

### 2.2 三种部署形态

| 形态 | 技术栈 | 启动方式 | 数据存储 |
|------|--------|----------|----------|
| V1 本地版 | Python http.server + HTML/CSS/JS | `python3 server.py` | `data/cards.json` |
| V2 云架构 | CloudBase 静态托管 + JS SDK | 浏览器访问 | localStorage + CloudBase DB |
| V3 小程序 | 微信小程序 web-view 壳 | 微信内打开 | localStorage + CloudBase DB |

## 四、学习建议算法

基于剩余次数和偏好时间段计算建议间隔：

```
剩余天数 = 到期日 - 今天
加权天数 = 工作日天数 × 权重1 + 周末天数 × 权重2
建议间隔 = ceil(加权天数总和 / 剩余次数)
```

权重默认值：工作日 × 1、周末 × 2

若 30 天内到期，显示紧急提醒并计算每周需完成次数。

## 五、同步策略

1. **冷启动**：首次使用时加载 3 条示例数据
2. **本地优先**：所有操作先写入 localStorage
3. **云端同步**：通过 updatedAt 比对，取新覆盖旧
4. **冲突处理**：以时间戳大的为准
5. **手动同步**：用户可在"设置"页手动触发同步

## 六、UI 设计

- 5 Tab 页：总览、签到、统计、评价、设置
- 避雷标识：评分≤2 的商家自动标注 ⚠️ 避雷
- 排序功能：最新/到期/剩余/评分
- 进度条：统计页展示各商家使用进度
- 响应式：桌面 1280px+ 和移动端适配
