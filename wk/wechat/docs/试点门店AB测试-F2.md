# F2 · 试点门店 A/B 测试设计

> 验证：次卡管家相对「原管理方式」是否真能降低客诉/漏单、提升核销透明度。
> 设计：门店级 A/B（非用户级，避免同店混用造成污染）。

## 1. 分组
- **对照组（A）**：维持原方式（纸质/Excel/旧 SaaS），3–4 家。
- **实验组（B）**：启用次卡管家，3–4 家（同城市、同业态、月发卡量相近）。

## 2. 核心指标（北极星 + 护栏）
| 指标 | 定义 | 采集方式 |
|---|---|---|
| 客诉率 | 次卡相关投诉单 / 核销笔数 | 后台标签 + 门店周报 |
| 漏单率 | 系统记录核销 ≠ 实际服务的笔数 / 总核销 | 店长每日抽检 10 笔 |
| 核销记录查询使用率 | 顾客自助查余次次数 / 活跃卡数 | 前端埋点 |
| 复购率 | 卡到期后 30 天内再购比例 | 订单系统 |

## 3. 周期与样本
- 周期：**4 周**（2 周预热 + 2 周观测，避开大促）。
- 每组门店月核销 ≥ 500 笔，确保差异显著（α=0.05, power=0.8 约需每组 ~6 家；先 3–4 家做方向性验证）。

## 4. 实验护栏（避免偏差）
- 实验组必须完成**员工培训 + 顾客引导话术**，否则数据无效。
- 同一顾客不可跨组（按首单门店锁定）。
- 提前定义「成功阈值」：客诉率↓≥30% 且 漏单率↓≥50% 视为有效增益。

## 5. 分析
- 周维度对比 A/B 指标均值 + 置信区间；
- 定性补充：实验组店长访谈（省了多少对账时间）。
- 输出《试点结论》：是否全网推广、哪些业态增益最大。

## 6. 验收
- [ ] 分组随机且同质（月发卡量差异 <20%）
- [ ] 指标埋点/采集口径对齐
- [ ] 达到预设成功阈值 → 进入推广决策
