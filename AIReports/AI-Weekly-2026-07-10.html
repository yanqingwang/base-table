🔓 2. Fable 5 回归：AI 治理进入"逐案审查"新常态

19 天禁令结束，但规则已永久改变 DEEP

7/1 全球恢复：Fable 5 在 6/12 被商务部以出口管制强制全球下线后，于 7/1 恢复。7/7 前订阅用户（Pro/Max/Team/企业高级席）可用至每周额度 50%；之后转按量计费 $10/$50 per MTok，标准企业席须立即走使用额度。Mythos 5 仍仅限美国获批机构（Glasswing 计划）。

政府审查机制定型：商务部"视同出口"（deemed export）原则现已延伸至云端 API 提供的商用前沿模型——任何模型理论上可被"无预警全球停服、且盟友无豁免"。6 部委（NSA、财政部、CISA 等）须在 8/1 前交付分类基准，但"不会有 AI 的 FDA"（前白宫 AI 顾问 Sriram Krishnan）。CASI 目前实际主导。结论：逐案谈判成为行业唯一结算机制，催生 19 天全球断供的条件并未根本改变。

OpenAI 的"绿灯"路径：GPT-5.6 先限"政府批准的组织"预览两周，再于 7/9 获公开放行。Altman 称过程涉及与 Lutnick、Bessent、Cairncross 等官员沟通，但评测专家与方式不透明。OpenAI 自己也表示"政府前置审查不应成为长期默认"。

🤖 3. ChatGPT Work：Agent 成为"产品"，Codex 并入 ChatGPT

从"聊天工具"到"自主工作者"

OpenAI 将 Codex（原开发者 Agent）并入 ChatGPT 桌面 App，并推出 ChatGPT Work——一个跨应用、跨文件、可执行数小时复杂项目并交付成品（Excel/Word/网页 App）的 Agent。统一插件目录首批接入 Google Drive、SharePoint、Slack、Teams、Gmail、Outlook、Salesforce、Adobe、Zoom、LinkedIn、GitHub、Canva、Dropbox 等，可用 @ 唤起或自动识别数据源。

配套能力：ChatGPT Sites（自然语言建站、部署、实时链接）、Ultra 模式（多 Agent 并行处理长任务）、Auto-Review（对抗红队中 100% 拦截受保护数据提取）。桌面 App（Mac/Windows）对所有套餐（含免费）开放 Chat/Work/Codex；Web/移动端先放 Pro/Enterprise/Edu，Plus/Business 数日内跟进。

分析：这被普遍视为 OpenAI 向"超级 App"的关键一步，也与 Anthropic 从 Claude Code 转向 Cowork 的路线呼应——编程 Agent 正升级为通用知识工作 Agent。Constellation Research 的 Holger Mueller 指出企业采纳仍是 OpenAI 的短板，ChatGPT Work 当前已超百万用户，但需快速获得与竞品相当的牵引。

🇨🇳 4. 中国拟人化 AI 新规：消费陪伴 vs 企业 Agent 强制分野

7/15 生效，全球首个"人格层"监管先例

北京《人工智能拟人化交互服务暂行规定》将于 7/15 生效，覆盖"模拟人类人格特质、思维方式与沟通风格、提供持续情感交互"的服务，点名极端思想、隐私泄露、身心健康损害、依赖成瘾四类风险。客服、知识问答、职场助手、教育、科研工具明确豁免（只要不做持续情感交互）。

执行节奏精准卡线：通义"拟人化交互 Agent 及用户自建 Agent"7/10 下线、广义 Agent 功能 7/15 下线；豆包 Agent 功能 7/15 下线，对话数据 10/15 后不可恢复——监管者要清的是"数据层"的陪伴足迹，而非仅关界面。企业版 Agent（火山引擎运行时、通义企业 API、元宝企业线）不受影响。

全球意义：这是首个监管者把"用户与 Agent 的关系"与"对话历史"纳入合规范围的先例。欧盟与美国正研究同类思路——在保持企业 Agent 生产力的同时切断消费端情感依赖。中国 6 月发布的 Agent 互联互通国家标准（架构/身份码/身份管理/描述/发现/交互/工具七层）为平台级执行提供了技术抓手。

💸 5. 价格战与开源崛起：OpenRouter 三巨头份额 55%→33%

美国管制"意外"喂大开源

TechXplore 报道：美国对 Anthropic、OpenAI 顶级模型的限制反而推高开源（尤其中国）模型兴趣。在路由多模型的 OpenRouter 上，Google/Anthropic/OpenAI 合计使用份额从 1 月的 55% 降至 6 月的 33%，中国 DeepSeek 明显领先。GLM-5.2（MIT 许可、1M 上下文）与 DeepSeek V4（Pro 1.6T/49B 激活、Flash 284B/13B 激活、1M 上下文）持续吸粉。

西方阵营中法国 Mistral 几乎独撑开源大旗；Meta 已淡出开源倡导。专家警告：当开源模型足够强，政府管制也可能延伸至开源——"若 Mythos 级模型被视为风险，中国也不会愿其开放"。价格下探 + 可获得性，正改变企业采购逻辑。

🔎 本期深度趋势解读

1. 🚀 "发布即 commodity"——前沿模型的稀缺性正在蒸发

48 小时内四款前沿模型同台，且定价集体下探到 $1–6 输出区间。核心信号：能力差距在收敛，成本与可靠性成为新战场。当 GPT-5.6 Luna 以 $1/$6、Muse Spark 1.1 以 $1.25/$4.25 提供"够用"的前沿能力，Anthropic 的 $10/$50 高端定价承压。行业正从"谁的模型最强"转向"谁的 Agent 最便宜、最可靠、最安全"。

2. 🔓 政府成为"影子发布经理"——模型上线需过政治关

Fable 5 的 19 天禁令与 GPT-5.6 的"政府批准预览→公开"路径，共同确认：美国前沿模型发布已事实纳入政府前置审查。企业须假设"单模型全球部署"存在被无预警中断的风险敞口，多云/多模型策略从最佳实践变为生存必需。8/1 前 6 部委框架若仍模糊，"逐案谈判"将持续。

3. 🤖 Agent 产品化：从"功能"到"可计费的数字员工"

ChatGPT Work、Muse Spark 1.1 多 Agent 编排、Claude Cowork 同步指向同一趋势：Agent 不再依附于聊天框，而是独立的产品形态与计费单元。OpenAI 用 Usage Credits 统一 Codex/Work/Excel/Workspace 的消费池；Anthropic 早将 Agent SDK 独立计量。下一步将是 Agent SLA、Agent 保险、Agent 审计等新业态。

4. 🇨🇳 中国"监管+创新"双轨的精密拆分

拟人化新规的精妙在于"按使用场景切"：消费陪伴（情感依赖）被清退，企业 Agent（生产力）被鼓励。这与 6 月 Agent 互联互通国标、MIIT 安全/实用/标准化导向构成"政策+标准+协议"组合拳。结果是同一个 Qwen/豆包 API，消费端不能做情感关系、企业端可以——这种"人格层"拆分可能被欧美借鉴。

5. 💸 开源拐点：管制红利 vs 管制外溢风险

OpenRouter 三巨头份额 55%→33% 是开源（尤其中国）模型的强信号。但 Ethan Mollick 等提醒：当开源模型达 Mythos 级，各国政府都可能将其锁定。短期红利（可获得性 + 低价）真实存在，长期"开源是否安全"将成为新博弈点。DeepSeek V4-Flash 的本地 GGUF 量化进一步降低部署门槛，边缘与私有化场景受益。
