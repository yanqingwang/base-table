# 测试案例
- [ ]  排课的时候，老师可以在日历上直接设置每次课长，开始时间，结束时间，休息时长，然后自动排课。一旦有选择后不能取消排课，否则可以对其中的某一个课进行取消，排课的时候考虑资源管理--教室等为核心。是否可以根据排班日历，然后学员可以直接在线预约，在线预约可以确认。确认后自动签到记录。请检查相关功能，瓦城开发和验证。
- [ ] 企业端应该包括多个层面。一个是租户层管理，里面增加客户，仅仅是企业授权管理者。第二个是客户管理员，管理员等于店长时，就是单店经营。如果是多个店铺，则管理员作为进一层的分类，可以分别管理自己的店员，但是发布的产品，可以跨店消费（可以对不同产品有不同设置，部分仅限本店，部分可以跨店 -- 同一个客户。）
