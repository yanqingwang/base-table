# Awesome Frontend Agent Skills - finfin/awesome-frontend-skills

Source: https://github.com/finfin/awesome-frontend-skills

A curated list of frontend-related Agent Skills repositories with SKILL.md files.

## Installation
```bash
npx skills add <owner/repo> --skill <skill-name>
npx skills add <owner/repo> --list
npx skills add <owner/repo> --skill <name> -a claude-code -a cursor
npx skills add <owner/repo> --all
```
