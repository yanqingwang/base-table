# 第一部分：产品文档（Product Documentation）

## 1. 产品定义

### 1.1 产品愿景

> **"东南亚蓝领入职管理第一平台：连接中介、企业和工人，让每个蓝领工人的入职流程在指尖完成。"**

### 1.2 产品定位

DL Hire 是一个覆盖蓝领员工 **从招募到上岗全生命周期** 的数字化入职管理平台，核心覆盖：

```
Agency协同 → 面试管理 → 极速审批 → 电子入职 → 培训考核 → EHS合规
```

与KonekBuhay专注招聘环节不同，DL Hire将战线延伸至入职后阶段，提供更完整的蓝领员工生命周期管理。

### 1.3 核心差异化（vs KonekBuhay）

| 维度 | KonekBuhay | DL Hire |
|------|-----------|---------|
| 覆盖环节 | 招聘（ATS+AI筛选） | 招聘 + 入职 + 培训 + EHS |
| 目标市场 | 仅菲律宾 | 菲律宾 + 马来西亚 + 泰国 |
| Agency协同 | ❌ 无 | ✅ 核心功能 |
| 电子合同 | ❌ 无 | ✅ 包含 |
| EHS培训 | ❌ 无 | ✅ **独家差异化** |
| WhatsApp集成 | ❌ 未提及 | ✅ 规划中 |
| AI能力 | ✅ 简历解析/筛选 | ✅ 同等+培训智能推荐 |

## 2. 用户画像与角色

### 2.1 用户角色定义

| 角色 | 代号 | 描述 | 核心需求 |
|------|------|------|---------|
| **求职者（Worker）** | BCW | 蓝领工人、工厂操作员、建筑工、物流人员、服务员 | 找工作、投递简历、接收面试通知、签署合同、完成培训 |
| **招聘HR（Recruiter）** | RE | 企业HR负责蓝领招聘的员工 | 发布职位、管理候选人筛选、安排面试、录用审批 |
| **审批管理者（Manager）** | MGR | 部门主管/工厂经理/HR总监 | 移动端审批录用、查看招聘进度、培训完成情况 |
| **劳务中介（Agency）** | AGY | 劳务派遣公司操作员 | 批量导入候选人、查看面试反馈、追踪入职状态 |
| **培训师（Trainer）** | TRN | EHS/技能培训讲师 | 上传课程、追踪培训进度、生成培训报告 |
| **系统管理员（Admin）** | ADM | IT支持/系统运维 | 系统配置、角色管理、数据导出、合规审计 |

### 2.2 用户旅程地图

#### 求职者旅程

```
发现机会 → 简历建档 → 投递职位 → 面试通知 → 面试签到 → 录用通知 → 电子签约 → 入职培训 → EHS考核 → 正式上岗
  ①         ②           ③         ④          ⑤          ⑥          ⑦         ⑧         ⑨         ⑩
```

#### 招聘HR旅程

```
职位创建 → 导入候选人 → AI筛选 → 面试安排 → 面试评价 → 录用推荐 → 审批跟进 → 入职确认 → 培训跟踪 → 转为正式员工
  ①         ②           ③         ④          ⑤          ⑥         ⑦          ⑧         ⑨         ⑩
```

#### 劳务中介旅程

```
登录协同端口 → 批量导入候选人CSV → 分配面试时间 → 候选人签到 → 查看面试结果 → 跟进录用 → 确认入职
    ①              ②                  ③              ④            ⑤             ⑥         ⑦
```

### 4.2 技术栈选择

| 层级 | 技术 | 选型理由 |
|------|------|---------|
| **前端框架** | React 18 + Vite | 现代、高效、生态丰富 |
| **前端状态** | Zustand（vs Context API） | 简单、性能好、适合中等规模 |
| **UI组件** | Ant Design / Chakra UI | 企业级组件库，多语言支持好 |
| **国际化** | react-i18next | 支持EN/TL/MS/TH/ZH多语言 |
| **移动端** | PWA（渐进式Web应用） | 无需应用商店发布，蓝领手机可直接访问 |
| **后端框架** | Rust + Axum | 高性能、内存安全、已有 `hris_tools` 基础 |
| **数据库** | PostgreSQL (生产) / SQLite (开发) | 从 SQLite 平滑迁移 |
| **缓存** | Redis | 会话管理、缓存、速率限制 |
| **对象存储** | MinIO (自建) / S3 (AWS) | 文档/证书/图片存储 |
| **AI/ML** | Python + FastAPI（微服务） | LLM调用、简历解析、NLP处理 |
| **AI模型** | OpenAI GPT-4 / Claude API | 简历解析、候选人匹配 |
| **OCR** | PaddleOCR（自部署） | 身份证/银行卡识别 |
| **消息推送** | WhatsApp Business API + Twilio SMS | 蓝领首选触达渠道 |
| **CI/CD** | GitHub Actions + Docker + Docker Compose | 标准SaaS实践 |
| **监控** | Sentry + Prometheus + Grafana | 错误追踪 + 性能监控 |
