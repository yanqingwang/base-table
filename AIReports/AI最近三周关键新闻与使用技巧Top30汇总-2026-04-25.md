1. **Claude Code 定位**：不是单纯代码补全，而是能理解项目结构、执行复杂开发任务、记住项目上下文并注重安全的编程助手。[citation:8]

3. **任务流程**：理解需求 → 制定计划 → 执行任务 → 验证结果 → 报告完成。[citation:8]
4. **Agent Mode**：支持自主决策、多步骤任务、错误恢复、进度报告和检查点。[citation:8]
5. **MCP 集成**：可通过 filesystem、github、brave-search、puppeteer、sqlite 等服务扩展外部工具和数据源。[citation:8]
6. **提示原则**：清晰上下文、指定风格/格式/约束、分解复杂任务、利用项目上下文。[citation:8]
7. **安全原则**：不共享 API Key、审查生成代码、保护敏感数据、谨慎使用外部代码、定期更新版本。[citation:8]

## 四、推荐组合工作流

### 4.1 新闻研究工作流

1. 明确时间窗口和主题范围。
2. 先抓官方来源，再补媒体和第三方分析。
3. 每条新闻输出“事件—证据—影响—后续观察”。
4. 用引用编号沉淀 Sources Inventory。

### 4.2 编程 Agent 工作流

1. 先读取项目说明和相关文件。
2. 搜索相似实现和测试。
3. 制定文件级修改计划。
4. 小步修改，立即验证。
5. 输出变更摘要、验证结果和剩余风险。

### 4.3 Claude Code 高效使用工作流

1. 使用清晰上下文描述任务，不使用“帮我优化这个”等模糊请求。[citation:8]
2. 对复杂任务分步骤，例如“先建模型、再建 API、再建前端、最后测试”。[citation:8]
3. 使用项目上下文，让 Claude Code 基于现有认证模块、支付模块、API 约定等进行修改。[citation:8]
4. 对外部能力使用 MCP，例如 filesystem、github、brave-search、puppeteer、sqlite。[citation:8]
5. 对生成结果做安全、测试、类型和构建验证。[citation:8]
