## 🏆 认证体系路线图

```
CSA (Certified System Administrator)
    ↓ 3-6 个月经验
CAD (Certified Application Developer) ← 可选但推荐
    ↓ 参与 1-2 个 HRSD 项目
CIS-HRSD (Certified Implementation Specialist - HR)
    ↓ Now Assist 实践经验
Now Assist for HRSD Bootcamp 认证
    ↓ 架构师方向
CTA / CMA (Certified Technical/Master Architect)
```

**平均时间**：CSA 3个月 → CIS-HRSD 6-12个月 → CTA/CMA 2-3年

## 👤 按角色定制

| 角色 | 重点 | 跳过 | 推荐课程 | 时间 |
|------|------|------|----------|------|
| **HR 管理员** | 门户/案例/知识库 | 开发/API 集成 | HRSD Fundamentals + Now Assist Essentials | 40-60h |
| **开发者/顾问** | Flow Designer/Spoke/AI Agent | — | CSA + CAD + CIS-HRSD + Bootcamp | 200-300h |
| **项目经理** | 方法论/干系人管理 | 编码 | HRSD Fundamentals + Credentialing Guide | 60-80h |
| **架构师** | CSDM/Fabric/AI 治理 | — | CTA + 多域经验 | 300-500h |
