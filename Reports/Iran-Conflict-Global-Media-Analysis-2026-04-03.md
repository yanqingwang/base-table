## 1. Scope, definitions, and method

### 1.1 Language / sphere buckets

- Chinese-language sphere
- English-language sphere (US/UK + wire services)
- Arabic-language sphere (incl. Gulf media ecosystem)
- European languages (French/German/Spanish)
- Russian-language sphere (optional; only if evidence is strong)

### 1.2 Media evidence types (include/exclude)

**Include:** publicly accessible major media reporting/analysis, wire stories, transcriptable interviews; official statements *only when clearly labeled as originals and/or quoted by media with proper attribution*.

**Exclude:** non-verifiable material; using social-platform chatter as a stand-in for media stance; using government positions as a proxy for public opinion.

### 1.3 Stance coding + uncertainty

To avoid pseudo-precision, we use a conservative 5-level ordinal code plus uncertainty fields:

- **+2 Strong Support**
- **+1 Support**
- **0 Neutral / Mixed**
- **-1 Opposition**
- **-2 Strong Opposition**
- **NA Insufficient Evidence**

Additional fields:

- **Confidence:** High / Medium / Low
- **Evidence balance:** Convergent / Mixed / Sparse

**Shift rule (since Feb 28):** for many media spheres we do not have a verifiable pre–Feb-28 baseline in the current ledger. Therefore, “shift” is operationalized as a **within-post–Feb-28 phase change** when two phases have sufficient verifiable samples:

- Phase 1: 2026-02-28 .. 2026-03-06
- Phase 2: 2026-03-17 .. 2026-03-29
