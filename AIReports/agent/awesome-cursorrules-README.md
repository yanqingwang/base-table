# Awesome Cursor Rules - PatrickJS/awesome-cursorrules

Source: https://github.com/PatrickJS/awesome-cursorrules

39k+ stars | 3300+ forks

A curated collection of Cursor AI project rules (.mdc files) that enhance the Cursor AI editor with project-specific coding standards, framework guidance, and reusable behaviors.

## Rule Format (.mdc)

Each rule uses YAML frontmatter with:
- description: One-line summary
- globs: File patterns where rule auto-attaches
- alwaysApply: Whether rule applies to every request
