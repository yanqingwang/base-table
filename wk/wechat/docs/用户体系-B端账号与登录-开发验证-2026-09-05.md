# 用户体系（B 端账号 · 登录 · 会话）开发与验证说明

**日期：2026-09-05**　·　载体：`code/card-counter-commercial`（网页版演示仓，先行实现自验，后续移植生产）
**结论：商业级 B 端用户体系已搭建。密码登录 + Bearer 会话 + 角色权限闭环 + 账号管理，全量测试 98/98 通过（新增 TestUserAuth×9），HTTP 真机冒烟通过。**

---

## 一、为什么做 & 审计结论

原系统鉴权为**演示头**（`X-Merchant-Id/X-Staff-Id/X-Customer-*/X-Platform-Admin` 直接传 ID），无账号、无密码、无登录/会话/登出/改密/启停用 —— 不能直接作为商业应用交付。

用户拍板方案：**覆盖平台超管 + 企业员工（B 端优先）**；**密码登录 + 不透明 Bearer 会话（存库可吊销、12h 过期、PBKDF2 加盐）**；交付 **API+单测+文档**（网页 UI 暂保留演示身份，文档注明）。

---

## 二、数据模型

| 表 | 字段 | 说明 |
|---|---|---|
| `user_account` | actorType(platform_admin\|staff), actorId, username(唯一), passwordHash, status(active/disabled), lastLoginAt | 一 actor 一账号（(actorType,actorId) 唯一）；顾客沿用 openid 体系，预留扩展 |
| `auth_token` | accountId, token(唯一), expiresAt, revokedAt | 不透明会话；登出置 revokedAt；默认 12h 过期 |

密码存储：`PBKDF2-HMAC-SHA256`（120k 迭代 + 16B 随机盐），格式 `pbkdf2$iter$salt_b64$hash_b64`。

## 三、API 契约（新增 `/api/auth/*`）

| 方法/路径 | 鉴权 | 说明 |
|---|---|---|
| POST `/api/auth/login` | 公开 | {username, password} → {token, expiresIn, account}；错误统一 401「用户名或密码错误」（不泄漏用户是否存在） |
| POST `/api/auth/logout` | Bearer | 吊销当前会话 |
| GET `/api/auth/me` | Bearer | 当前账号 + actor：staff 含 merchantId/merchantName/isOwner/role/permissions |
| PATCH `/api/auth/password` | Bearer | {oldPassword, newPassword(≥8)}；改密后**吊销该账号全部历史会话** |
| GET `/api/auth/accounts` | 平台=全部；企业(owner/manage_staff)=本企业员工 | 账号列表 |
| POST `/api/auth/accounts` | 同上 | {actorType, actorId, username?, initialPassword?} → 返回 initialPassword（一次） |
| PATCH `/api/auth/accounts/<id>/status` | 同上 | {status: active\|disabled}；停用即吊销其会话 |

平台开通企业（POST `/api/platform/merchants`）现在**自动为授权管理员建登录账号**（username=`admin{merchantId}`），可传 initialPassword 或返回随机初始密码。

## 四、鉴权接入（双轨，向后兼容）

- **Bearer 优先于演示头**：`_staff()`（无 X-Staff-Id 时由 Bearer staff 解析并回填 merchantId）、`_platform_admin()`（无 X-Platform-Admin 时由 Bearer platform_admin 解析）均已升级；原 X-* 演示头全部继续可用（既有 89 个用例零回归）。
- 权限隔离仍走 `ensure_permission`（员工角色权限位）；平台接口仅平台角色可达。

## 六、测试矩阵（98/98 全绿；新增 TestUserAuth×9）

| 用例 | 关键断言 |

| logout_revokes | 登出后原 token me→401 |

| platform_account_management | 建员工账号→列表含→新账号登录→停用（登录 403、旧会话 401）→启用恢复 |

## 七、验证记录（HTTP 真机）

- 演示服务（http://127.0.0.1:8090，全新库）冒烟：admin1 登录→Bearer `/api/auth/me`→Bearer 建模板 200→旧演示头 `/api/merchant/cards` 回归 200→platform Bearer 租户列表 200→无 token `/api/auth/me` 401。
- 安全行为实测：改密吊销全部会话、停用账号即踢下线、错密码不区分用户、token 过期即拒。
