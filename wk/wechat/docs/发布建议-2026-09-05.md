## 阻塞点 1：小程序上传 IP 白名单

### 现象
```
[error] 20003 Error: {"errCode":-10008,"errMsg":"invalid ip: 183.192.126.7, ...}
```
微信小程序代码上传强制校验出口公网 IP，必须在 MP 后台「开发管理 → 开发设置 → 上传代码 IP 白名单」中加入当前出口 IP。

### 关键风险：出口 IP 不稳定
实测本机出口在不同时段/会话会变化（NAT 出口）：
| 时间 | 出口 IP | 协议 |
|------|---------|------|
| 上次会话 | 112.65.121.227 / 2408:820c:… | IPv4 / IPv6 |
| 本次（2026-09-05） | 183.192.126.7 | IPv4（IPv6 当前不可用） |

因此「加一个白名单 IP」是脆弱方案：下一次上传很可能需要再加新 IP。**推荐稳定出口方案**：

### 推荐处置（任选其一）
- **方案 A（推荐，最稳）：在固定公网 IP 的机器上传**
  在你本机或一台静态 EIP 云主机上执行：
  ```bash
  cd card-counter-miniapp
  node scripts/upload_ci.js 2.7.0 "feat: 顾客端 A/C/D/B (购买次卡/团购核销/应退估算) v2.7.0"
  ```
  只需把该机器的固定 IP 加入白名单一次，永久可用。
- **方案 B（临时）：白名单当前 IP 并立即重试**
  把 `183.192.126.7` 加入白名单，告诉我，我在此会话内立即重试（同一会话出口通常不变）。缺点是下次可能又变。
- **方案 C：白名单整个出口网段**（若微信后台支持 CIDR，且你信任该 NAT 网段）。

> 注意：`private.key` 已就位（appid `wx9c5974ab24d057c3`），上传凭据无需改动。上传成功后会进入「开发版」，需你在 MP 后台**提交审核 → 发布**才对线上用户生效。
