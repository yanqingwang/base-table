## 8. 风险与已知限制

1. **Bulk Send List API (`/bulk_envelope_lists`) 在当前 Demo 计划下 404**: 已用"循环单信封"路径绕开。 若需严格走 Bulk Send List, 需联系 DocuSign 销售启用 Batch Transactions 计划。
2. **`ross.wang@te.com` 账号 2FA**: 每次手动登录需输入 SMS 验证码。 JWT Grant 不需要 2FA, 但首次授权 (consent) 需要一次浏览器登录。
3. **HMAC secret 当前未在 DocuSign 后台启用**: `.env` 中已配置, 但 Connect Webhook 需在 Admin > Connect 页面手工配 (一次性)。 Webhook 服务端 (`docusign_webhook.py`) 在 secret 缺失时会打印告警, 不会崩溃。
4. **KR_Onboarding 模板多 tab 同 label**: 需先用 `?include=tabs` 拿到所有 tab 列表, 然后 XLSX 必须包含所有 required tabLabel 列, 否则 POST /envelopes 会返回 `REQUIRED_TAB_INCOMPLETE`。 模板列表参见 §5。
5. **tracking DB 没有 `timestamp` 列**: 是 `created_at` / `sent_at` / `completed_at` (ISO8601 字符串)。 与外部脚本对接时按需调整。
