## 4. 异常排查
| 现象 | 排查 |
|---|---|
| 镜像构建报错 → 查看「构建日志」 | 多半是 requirements.txt 缺包或 Dockerfile 路径不对 |
| 启动后「运行异常」看日志 | 优先看 `DB_URL` 路径权限：临时 `/tmp/...` 一般可写；若是 `data/cards.db` 容器重启会丢 |
| 公网访问 502 | 看启动日志中 gunicorn 是否监听 80；检查 PORT 环境变量是否传入（默认 5000） |
| 想用 MySQL | env prod 控制台「MySQL」可创建数据库 → 把 `DB_URL` 设为 `mysql+pymysql://<user>:<pwd>@<host>:3306/cardcount`，重建一次 |
