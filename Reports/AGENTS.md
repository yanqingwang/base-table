## Working with This Repository

### Adding New Documentation

1. Create new `.md` files in `/home/xiaowu/文档/AI/`
2. Use clear, descriptive filenames (kebab-case for English)
3. Include frontmatter metadata where appropriate

### Documentation Standards

- **Language**: English or Chinese (based on content)
- **Format**: Standard Markdown with tables for structured data
- **Headers**: Use hierarchical headers (# ## ###)
- **Links**: Relative links for internal references
- **Code blocks**: Fenced with language identifiers

### Content Categories

| Category     | Description                       |
| ------------ | --------------------------------- |
| Training     | AI tutorials, guides, how-tos     |
| Monetization | Business models, revenue methods  |
| Tool Manuals | Software documentation            |
| HR Services  | Industry-specific AI applications |
| Research     | Analysis reports, market studies  |

### File Naming Conventions

- Use lowercase with hyphens: `ai-training-manual.md`
- Chinese files: `AI技术报告.md`
- Series files: Use numbered prefixes `HR_AI_01_*.md`
- Analysis reports: `*_analysis_report.md` or `*_report.md`
