# F1 · SMB 半结构化访谈提纲（10–15 家）

> 验证：次卡/储值卡管理工具的**真实痛点强度**与**合规付费意愿**，决定 P1 是否值得押注。
> 对象：长三角 · 美业（美容/美甲/美发）、教培（少儿/成人）、健身（私教/团课）各 4–5 家，年营收 50–2000 万。

## 一、破冰（5min）
- 门店类型 / 员工数 / 月均发卡量 / 当前用什么管次卡（纸质？微信？有赞/美团？Excel？）

## 二、痛点挖掘（15min，情景式）
1. 上次因为「次卡算错/漏单/顾客扯皮」是什么时候？损失大概多少？
2. 顾客问「我这张卡还剩几次」时，你怎么答？当场能查到吗？
3. 员工离职/换班，次卡数据会丢或乱吗？
4. 现在发一张新卡，从「决定发」到「顾客能用」要几步？

## 三、合规认知（10min）
5. 你知道预付卡要在商务部/地方备案吗？（多数不知道 → 教育成本）
6. 如果工具帮你**自动生成备案材料 + 资金存管对接**，你愿意为「合规保险」多付一点吗？
7. 顾客最在意的是「不退费」还是「随便退」？（影响退费规则设计）

## 四、付费意愿（10min，价格锚点）
8. 下面哪个年费你能接受，且**会主动续费**？
   - A. ¥299/年（基础核销+卡包）
   - B. ¥599/年（+合规备案助手+多门店）
   - C. ¥999/年（+数据看板+顾客运营）
   - D. 抽佣 1% 交易额（不预收年费）
9. 你更接受「年费」还是「按发卡抽佣」？为什么？

## 五、打分（收尾）
请对以下维度 1–5 分打分（5=极痛）：
- 漏单/算错次卡的痛
- 顾客查余次的痛
- 合规风险的焦虑
- 多门店数据割裂的痛

## 分析交付
- 每类目 ≥3 家 → 痛点强度排序；
- 付费意愿分布（A/B/C/D 占比）→ 定价区间建议；
- 输出《SMB 验证结论》：P1 合规是否真有付费意愿、建议首发定价。
