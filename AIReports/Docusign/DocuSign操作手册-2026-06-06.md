## 二、创建模板

### 2.1 什么是模板

模板就是提前做好的文件格式。你上传一份 PDF，在需要填写和签名的地方放好"空位"，以后每次发的时候，系统会自动把空位填好。

### 2.2 创建模板步骤

**第一步：准备文档**

用 Word 做好文档，在需要填写的地方加上标记（Anchor String），例如：

```
录用通知书

候选人姓名：/candidate_name/
职位：/position/
薪资：/salary/
入职日期：/start_date/

候选人签名：/candidate_sign/
HR 签名：/hr_sign/
```

把 Word 转成 PDF。

**第二步：进入模板页面**

1. 登录 `https://admindemo.docusign.com`
2. 点击左侧导航的 "Templates"（模板）
3. 点击右上角的 "Create Template"（创建模板）

**第三步：上传文档**

1. 给模板起个名字，比如 "Offer Letter"
2. 上传做好的 PDF 文件
3. 点击 "Next"（下一步）

**第四步：添加签署角色**

1. 点击 "Recipients"（收件人）
2. 添加角色：
   - 角色名：`候选人`，类型：Signer（签署人），顺序：1
   - 角色名：`HR`，类型：Signer（签署人），顺序：2
3. 顺序 1 的人先签，签完才轮到顺序 2

**第五步：放置填写字段**

1. 在文档预览中，从右侧拖拽字段到对应位置
2. 常用字段：
   - **Sign Here**（签名）：放在签名处
   - **Text**（文本）：放在需要填文字的地方
   - **Date Signed**（日期）：自动显示签署日期
   - **Checkbox**（复选框）：放在需要勾选的地方
   - **List**（下拉列表）：放在需要选择的地方
3. 每个字段可以设置：
   - **Data Label**（数据标签）：给字段起个英文名，比如 `candidate_name`
   - **Default Value**（默认值）：可以预填的内容
   - **Required**（必填）：勾上表示必须填写

**第六步：保存模板**

1. 检查所有字段位置是否正确
2. 点击 "Save"（保存）
3. 记录模板 ID（一串字符，后面批量发送要用）

### 2.3 6 个标准模板清单

| 模板名称 | 谁签 | 说明 |
|---|---|---|
| Offer Letter | 候选人 + HR | 录用通知书 |
| 个人信息授权书 | 候选人 | 个保法授权 |
| NDA 保密协议 | 候选人 + HR | 保密协议 |
| 个人信息采集表 | 候选人 | 员工档案信息 |
| 银行账户采集表 | 候选人 | 发工资用 |
| 证件采集表 | 候选人 | 上传身份证照片 |

## 三、准备员工数据 Excel 表格

### 3.1 表格格式

使用系统提供的 Excel 模板（6 个工作表），模板位于：
```
/home/wang/wk/code/docusign-keys/onboarding/onboarding_data_template.xlsx
```

模板包含以下工作表：

| 工作表 | 内容 | 关键字段 |
|--------|------|----------|
| Employee Info | 员工基本信息 | employee_id, employee_name, employee_email, phone, gender, date_of_birth, id_card_number, address, emergency_contact, emergency_phone, highest_education, nationality, marital_status |
| Contract Info | 合同信息 | employee_id, position, department, base_salary, salary_currency, contract_start_date, contract_end_date, work_location |
| NDA & Authorization | 保密协议和授权 | employee_id, nda_company_name, nda_date, nda_disclosure_period, privacy_consent_date, privacy_purpose, data_retention_years |
| Bank Info | 银行账户 | employee_id, bank_name, bank_account, bank_account_name, bank_branch |
| ID Documents | 证件信息 | employee_id, id_card_type, id_card_number, passport_number, work_permit_number, visa_type |
| Attachments | 附件清单 | employee_id, attachment_type, attachment_description, file_path |

### 3.2 填写说明

- **复制模板后再填写**，不要修改原始模板
- **每行一个员工**，`employee_id` 列是各表之间的关联键（同一员工在所有表中使用相同的 employee_id）
- **第一行是说明行（灰色背景）**，第二行才是表头，从第三行开始填写数据
- **不需要的列留空即可**，不会影响发送
- **不需修改列名**，列名必须与程序中 FIELD_MAP 的字段名一致
- **员工邮箱必须正确**，错了候选人收不到邮件

模板已包含一条示例数据（张三，EMP001），使用时请删除示例行替换为真实数据。

```bash

```

然后用 Token 调用 API：
```bash
curl -H "Authorization: Bearer $(python3 docusign_auth.py --show-token 2>/dev/null)" \
  "https://demo.docusign.net/restapi/v2.1/accounts/45445035/envelopes/{envelope_id}"
```

**状态说明：**
| 状态 | 说明 |
|------|------|
| created | 已创建 |
| sent | 已发送，等待签署 |
| delivered | 收件人已查看 |
| completed | 所有人已完成签署 |
| declined | 已拒绝 |
| voided | 已作废 |

### 6.3 使用监控脚本查看实时状态

```bash
# 持续监控（每 10 秒刷新一次）
python onboarding/onboarding_status.py --account 45445035 --watch 10
```

## 八、批量入职自动化流程

### 8.1 数据准备

| 工作表 | 内容 | 字段数 |
|--------|------|--------|
| Employee Info | 员工基本信息（姓名、电话、身份证、住址等） | 18 |
| Contract Info | 合同信息（职位、部门、薪资、合同期限等） | 16 |
| NDA & Authorization | 保密协议和隐私授权（保密期限、授权用途等） | 8 |

2. 每行一个员工，`employee_id` 列是各表之间的关联键

### 8.2 批量发送入职文档

填写好 Excel 后，运行以下命令发送入职文档：

```bash

python onboarding_send.py \
    --xlsx /path/to/onboarding_data.xlsx \
    --account 45445035

# 先试发送（不实际发出，仅验证）
python onboarding_send.py \
    --xlsx /path/to/onboarding_data.xlsx \
    --account 45445035 \
    --dry-run

# 只发送特定文档类型（如录用通知书 + NDA）
python onboarding_send.py \
    --xlsx /path/to/onboarding_data.xlsx \
    --account 45445035 \
    --doc-types offer_letter nda

    --xlsx /path/to/onboarding_data.xlsx \
    --account 45445035 \
    --template-map '{"offer_letter":"<TEMPLATE_ID>", "nda":"<TEMPLATE_ID>"}'
```

## 九、常见问题（FAQ）

### Q1: 候选人说没收到邮件怎么办？

1. 先检查邮箱地址是否正确
2. 让候选人检查垃圾邮件箱
3. 在 DocuSign 中查看信封状态，如果是 "Sent" 说明已发出
4. 如果确实没收到，可以重新发送

### Q2: 候选人不会操作签署页面怎么办？

1. 告诉候选人：打开邮件里的链接
2. 点击文档中的黄色标记位置
3. 选择签名样式（可以手写、打字或上传图片）
4. 填写需要的信息
5. 点击 "Finish"（完成）

### Q3: 批量发送时有些人的邮箱写错了怎么办？

1. 先查看批量发送状态，找到失败的那些
2. 修正 Excel 中的邮箱
3. 单独重新发送（见第九章）

### Q4: 导出数据时提示 "401 Unauthorized"？

1. 可能是 Token 过期了
2. 重新运行脚本即可自动刷新
3. 如果持续报错，联系 IT 支持

### Q5: 一个候选人需要签多个模板怎么办？

目前需要分多次发送。例如：
1. 先发 Offer Letter
2. 等候选人签完
3. 再发个人信息授权书 + 个人信息采集表 + 银行账户采集表 + 证件采集表（可以合并到一个信封）

### Q6: 候选人用手机能签吗？

可以。DocuSign 支持手机浏览器签署，字段会自动适配屏幕大小。

### Q7: 签署的文件有法律效力吗？

有。DocuSign 电子签名符合《中华人民共和国电子签名法》，与手写签名具有同等法律效力。每个信封都有完整的审计跟踪记录。

## 十、紧急情况处理

### 10.1 如何撤销已发送的信封

**方法一：网页端操作**
1. 登录 `https://apps-d.docusign.com`
2. 进入 Envelopes 页面
3. 找到要撤销的信封
4. 点击右侧的 "More"（更多）
5. 选择 "Void"（作废）
6. 填写作废原因
7. 确认

**方法二：API 操作**
```bash
# 通过 API 撤销
python docusign_auth.py --force
# 获取 token 后，手动调用 API：
ENVELOPE_ID="xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
TOKEN=$(python3 docusign_auth.py --show-token 2>/dev/null)
curl -X PUT "https://demo.docusign.net/restapi/v2.1/accounts/45445035/envelopes/${ENVELOPE_ID}" \
  -H "Authorization: Bearer ${TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"status": "voided", "voidedReason": "候选人信息有误，需重新发送"}'
```

### 10.2 如何重新发送

**方法一：网页端操作**
1. 找到已作废的信封
2. 重新准备候选人数据
3. 重新运行批量发送

**方法二：修正后重新发送**
1. 修正 Excel 中的错误数据
2. 重新运行批量发送脚本
3. 新的信封会发送到候选人邮箱

### 10.3 候选人拒绝签署怎么办

1. 电话联系候选人，了解原因
2. 如果是信息有误，修正后重新发送
3. 如果候选人放弃入职，在系统中标记
4. 记录拒绝原因，便于后续改进

### 10.4 系统故障处理

| 故障现象 | 处理方式 |
|---|---|
| 无法登录 DocuSign | 检查网络，联系 IT 支持 |
| 批量发送脚本报错 | 截图报错信息，联系 IT 支持 |
| 数据导出失败 | 检查磁盘空间，重试 |
| Connect 通知未收到 | 联系 IT 检查 Webhook 服务 |
