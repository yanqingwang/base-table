# DocuSign 模板制作与数据导入标准操作手册

**报告日期：2026年06月07日**

---

## 执行摘要

本文档总结了在 DocuSign 平台进行模板制作和数据导入的完整工作流程，涵盖：
- 模板复制与角色管理
- 变量占位符处理（`[[Text()]]` 和 `{{Variable}}`）
- 中文字体渲染
- 签署附件上传（signerAttachmentTabs）
- 批量信封发送与验证

**核心结论**：DocuSign 演示账号不支持服务器端变量替换，必须采用「本地生成干净 PDF + 内联文档发送」的方式实现。

---

## 一、DocuSign 演示账号限制

| 限制项 | 说明 | 影响 |
|--------|------|------|
| 收件人数量 | 单个信封最多 2 个收件人 | 模板需移除第 3 个角色（如 HR RP） |
| `[[Text()]]` 占位符 | **不会自动替换** | 必须本地生成无占位符的 PDF |
| `{{Variable}}` 占位符 | **不会自动替换** | 同上 |
| 模板文档上传 | PUT 接口返回 400/INVALID_CONTENT_TYPE | 优先使用内联文档发送 |
| multipart/form-data | 返回 INVALID_CONTENT_TYPE | 不支持 |

## 二、标准工作流程

### 阶段 1：模板分析

```bash
# 1. 获取原模板详情
GET /v2.1/accounts/{accountId}/templates/{templateId}

# 2. 获取各文档的 tab 结构
GET /v2.1/accounts/{accountId}/templates/{templateId}/documents/{documentId}/tabs
```

**关键信息提取**：
- 文档列表（id、名称、fileExtension）
- 角色列表（roleName、recipientId、routingOrder）
- 所有 tab 类型与位置：
  - `signHereTabs`（签字位）
  - `dateSignedTabs`（签字日期）
  - `textTabs`（文本输入）
  - `signerAttachmentTabs`（文件上传）
  - `listTabs`（下拉框）
  - `numericalTabs`（数字）

### 阶段 2：模板复制

```python
# 复制原模板
POST /v2.1/accounts/{accountId}/templates
{
    "templateId": "原模板ID",
    "name": "新模板名称"
}
```

**注意**：复制后的模板 ID 已改变，但保留原文档结构。

### 阶段 3：下载原文档

```python
# 下载为原始二进制
GET /v2.1/accounts/{accountId}/templates/{templateId}/documents/{documentId}
Headers: Accept: application/json
```

**陷阱**：响应是原始二进制（不是 JSON），需要直接保存为 .pdf 文件。

### 阶段 4：分析变量位置

```bash
# 使用 pdftotext 获取 bbox 信息
pdftotext -bbox-layout /tmp/orig_doc1.pdf /tmp/_bbox.html
```

**提取变量位置**：
- 解析 `<word xMin="..." yMin="..." xMax="..." yMax="...">text</word>` 标签
- 按 y 坐标分组为行
- 找到包含 `{{Variable}}` 的行及其边界框

**字体大小分析**：
```bash
pdftohtml -xml -i -nodrm /tmp/orig_doc1.pdf /tmp/_orig.xml
# 解析 height 属性（单位：pt）
# 找出最常见的正文 font size
```

**本项目发现的字体**：
- 正文：18pt（Arial）
- 地址：15pt
- 标题：20pt

### 阶段 5：生成干净 PDF（核心步骤）

**方法：PDF → 图像 → 绘制 → 图像 → PDF**

```python
# 步骤 A：PDF 转 PNG（150 DPI）
subprocess.run(['pdftoppm', '-r', '150', '-png', pdf_path, output_prefix])

# 步骤 B：在 PNG 上绘制白矩形 + 值
from PIL import Image, ImageDraw, ImageFont
img = Image.open(image_path).convert('RGB')
draw = ImageDraw.Draw(img)
# 白矩形覆盖 {{Variable}} 文本
draw.rectangle([x1, y1, x2, y2], fill='white')
# 绘制实际值（18pt = 37px @ 150 DPI）
font = ImageFont.truetype('SimHei.ttf', 37)
draw.text((x1+2, y1-2), value, fill='black', font=font)
img.save(output_path, 'PNG', dpi=(150, 150))

# 步骤 C：图像转回 PDF
from reportlab.pdfgen import canvas
c = canvas.Canvas(output_pdf)
for img_path in image_paths:
    img = PILImage.open(img_path)
    c.setPageSize((w*72/150, h*72/150))
    c.drawImage(img_path, 0, 0, width=w*72/150, height=h*72/150)
    c.showPage()
c.save()
```

**坐标转换**：
- DPI = 150
- SCALE = 150/72 = 2.083
- 18pt = 18 × SCALE = 37.5px
- PDF 坐标 → 图像坐标：`x_img = x_pdf × SCALE`

**中文字体处理**：
- 使用 `/tmp/fonts/SimHei.ttf`（9.7MB，需从 GitHub 下载）
- 英文使用系统 sans-serif（Liberation Sans、DejaVu Sans 等）
- 检测 `\u4e00 <= ch <= \u9fff` 范围判断是否中文

## 五、踩过的坑（重要！）

1. **`PUT /templates/{id}/documents/{docId}` 返回 400**
   - 原因：JSON body 格式不被接受
   - 解决：使用内联文档方式发送信封

2. **multipart/form-data 返回 INVALID_CONTENT_TYPE**
   - 原因：DocuSign API 不支持
   - 解决：同 1

3. **`GET /templates/{id}/documents/{docId}` 返回原始二进制**
   - 原因：缺少 Accept header
   - 解决：直接保存为 .pdf

4. **`signerAttachmentTabs` 用字符串 xPosition/yPosition 不生效**
   - 原因：API 期望整数
   - 解决：改为整数

5. **DocuSign 模板复制后 `GET /templates/{id}/documents` 返回 0**
   - 原因：API 显示异常
   - 解决：通过 `GET /templates/{id}` 主接口查询

6. **`[[Text()]]` 和 `{{Variable}}` 在演示账号不替换**
   - 原因：演示账号无服务器端变量替换功能
   - 解决：本地生成干净 PDF（图像叠加方式）

7. **中文字符在 PDF 中显示为 ■**
   - 原因：Helvetica 不支持中文
   - 解决：中文用 SimHei.ttf 渲染为 PNG 图像

8. **PIL 字体大小单位是像素，需手动转换**
   - 公式：`px = pt × DPI / 72`
   - 18pt @ 150 DPI = 37px
